      🔋 Athan not playing when the tab is in the background? Tips for reliability
      • Keep the window visible (even small, at the side) rather than minimized — browsers suspend minimized windows most aggressively.
      • Chrome / Edge: open Settings → Performance and add this site under “Always keep these sites active” so Memory Saver never puts the tab to sleep.
      • Play the Quran (the Quran tab) — a tab that is actively playing audio is kept awake by the browser, so listening to the Quran also keeps the athan schedule running.
      • Install it as an app (browser menu → “Install” / “Add to Home Screen”) — an app window is treated better than a background tab.
      • Keep the computer awake: a sleeping computer stops everything. On a Mac: System Settings → Lock Screen → prevent sleeping; on Windows: Power settings.
      • If the tab was suspended anyway, the app catches up when it wakes: recently missed athans (within 10 minutes) still play, older ones are listed in the Activity tab.

          Install the Desktop App

          This website works everywhere with nothing to install — but for a permanent, always-on athan (menu-bar icon, auto-start when the computer turns on), there is a desktop application. It is one command, and the same command installs, updates and repairs it.

          git clone https://github.com/aparsi0/athan_app.git ~/Desktop/athan_app cd ~/Desktop/athan_app && ./setup.sh

          macOS and Linux. It installs whatever is missing — Homebrew, Python, Tkinter, VLC — upgrades whatever is out of date, runs the tests and builds the app. On Windows the equivalent is powershell -ExecutionPolicy Bypass -File .\setup.ps1.

          • 🌙 Start it at login (macOS)./setup.sh --autostart — the crescent in the menu bar, every login, keeping the Mac awake. ↗
          • 🪟 Windows 10 / 11The PowerShell equivalent, over winget. ↗
          • 📱 iPhone, iPad and AndroidNothing to install — this page is the full app. Add it to your home screen. ↗
          • 🛠 If something goes wrongWhat the setup checks, and the one command that fixes a broken install. ↗

          📱 On phones there is nothing to install: open this site and use your browser's “Add to Home Screen” / “Install” — it becomes an app with its own icon.

          Morning Quran

          Stop min after the Morning Azkar

          Starts when the Fajr athan and its duaa finish, and runs until the time above. The Morning Azkar falls inside that window and still takes priority — the Quran pauses for it and resumes afterwards. Opening the page mid-window picks up where it left off on this device. Like the athan and the Azkar, it takes over at its moment — and hands back afterwards: whatever Quran tab was playing is paused when it starts and resumes when the window ends, unless you have picked something else in the meantime.

          Location

          Lat Lon

          🔒 Your coordinates (and, for auto-detect, your IP address) are sent only to the prayer-time and geocoding services that need them — Aladhan, BigDataCloud, ipapi and ipwho — to calculate your times. Nothing is stored on any server, and there is no tracking or analytics. All your settings stay in this browser only. The athan, duaa and Azkar audio is served from this site, but the two Quran tabs (المصحف المعلم and إذاعة القرآن) stream from el-hosary.com and the station's servers — so those hosts can see your IP address while you listen. Opening those tabs without pressing play sends them nothing.
